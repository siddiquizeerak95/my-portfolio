## 4. End-to-End User Flows

1. **Visitor Inquiry Flow:** A visitor navigates to `https://zsstudio.netlify.app/contact.html`, fills out their message, and clicks Send. The browser encrypts the message with OpenPGP 4096-bit RSA, Netlify signs the proxy request, Render verifies the signature, and Resend dispatches the email in ~2.0 seconds. The visitor receives instant visual feedback (`✔ TRANSMISSION SECURELY DELIVERED`).
2. **Owner Receipt & Decryption Flow:** Zeerak receives the notification in Gmail, copies the ASCII-armored block (or downloads the `.eml`), and runs `node decrypt_message.js`. The offline tool decrypts the message locally without exposing private keys to the cloud.
3. **Developer Deployment Flow:** Developer pushes code to GitHub `main` &rarr; Render automatically builds and deploys the Node.js backend Web Service &rarr; Netlify automatically deploys static frontend assets &rarr; Zero credentials required in git repository.
