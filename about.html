// 01.1 PERSONAL STORY & SCHOLASTIC JOURNEY

My name is Zeerak Shafique. I am currently pursuing a Bachelor of Computer Applications (BCA), dedicating my days to understanding both how software computes at machine level and how humans experience software on the screen.

The Foundation: Respecting the Engine

When many aspiring developers enter software creation, the default instinct is to immediately reach for high-level frameworks and automated boilerplates. My academic journey has instilled an alternative ethos: learn the mechanics first.

Studying C programming taught me what actually happens when a program executes—how memory addresses are mapped, why pointer arithmetic matters, how data structures like linked lists, stacks, and binary trees organize information, and how algorithmic efficiency dictates real-world performance.

The Medium: The Open Web

On the front-end, I view the browser as an interactive spatial canvas. Instead of relying on rigid UI libraries that produce identical websites, I focus on the mastery of semantic HTML5 document architecture, mathematical CSS layouts using fluid clamp() equations, and modular vanilla JavaScript.

My goal is to bridge these two disciplines: taking the algorithmic discipline of systems programming and applying it to creative web development, interactive graphics, and digital experiences that leave a lasting emotional impression.
